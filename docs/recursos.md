# Recursos multimèdia

Pomodoro Studio no incorpora contingut protegit de tercers. Cada recurs utilitzat per a crear un vídeo ha de ser propi o tindre una llicència compatible amb l'ús previst.

## Fons

Ubicació:

```text
assets/backgrounds/
```

Formats previstos en la v0.1:

- JPG
- PNG
- MP4

Una imatge fixa es mantindrà durant tota la sessió. Un MP4 curt podrà repetir-se en bucle fins a completar la duració.

## Sons ambientals

Ubicació:

```text
assets/ambience/
```

Exemples:

- pluja;
- foc;
- vent;
- bosc;
- pàgines;
- tempesta;
- ones;
- ambient de taverna;
- ambient de nau espacial.

Cada pista tindrà un volum independent i es podrà activar o desactivar per projecte.

## Música

Ubicació:

```text
assets/music/
```

La música és opcional. Només s'ha d'utilitzar música pròpia, de domini públic o amb una llicència que permeta expressament l'ús corresponent.

## Tipografies

Ubicació:

```text
assets/fonts/
```

Les tipografies utilitzades també han de permetre l'ús previst. En absència d'una tipografia personalitzada, el sistema utilitzarà una font lliure disponible dins del contenidor.

## Traçabilitat

En versions posteriors cada recurs podrà tindre associades metadades com ara:

- autor;
- origen;
- tipus de llicència;
- URL d'origen;
- data d'obtenció;
- notes d'atribució.

Esta informació permetrà saber exactament quins recursos s'han utilitzat en cada vídeo.
