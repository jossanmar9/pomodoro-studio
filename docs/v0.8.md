# v0.8 — Ambientacions originals

La v0.8 prioritza la creació d'ambientacions originals assistida opcionalment per IA, avançant este bloc que inicialment estava previst per a la v0.9.

## Objectiu

Fer que Pomodoro Studio ajude a concebre i preparar una identitat visual original per a cada vídeo sense convertir cap proveïdor d'IA en una dependència obligatòria del nucli.

## Blocs implementats

### Constructor de prompts i composicions

`app/services/ambience_prompt.py` genera prompts positius i negatius amb tema, època, lloc, hora, clima, il·luminació, atmosfera, estil i detalls. Hi ha composicions per a fons 16:9 i miniatures amb espai de text a esquerra, dreta o focus central.

La interfície web carrega el constructor dins de la fitxa del projecte i permet copiar els prompts sense necessitar cap servei d'IA.

### Presets i variants pròpies

S'inclouen bases genèriques per a biblioteca, cabana, observatori, bosc, taverna i estació espacial. La UI permet guardar, recuperar i eliminar variants pròpies. Estes variants es conserven en `localStorage` del navegador, de manera que no exigixen migracions de base de dades en la v0.8.

### Control d'originalitat

El constructor rebutja referències directes a una primera llista de franquícies i universos coneguts. El prompt final reforça món original, arquitectura genèrica i absència de personatges, logotips o marques recognoscibles. És una protecció de producte, no una determinació jurídica automàtica.

### Importació i procedència

`app/services/ambience_assets.py` importa JPG, JPEG, PNG i WebP sense sobreescriure recursos existents i crea un JSON lateral amb prompt, prompt negatiu, proveïdor, model, llicència, notes, data i nom final.

### Proveïdors opcionals

`app/services/image_providers.py` manté una interfície comuna. El mode `manual` continua sempre disponible i no genera res automàticament.

La v0.8 incorpora un connector real per a **AUTOMATIC1111 / Stable Diffusion WebUI Forge** mitjançant l'API compatible `/sdapi/v1/txt2img`. Usa `httpx` i valida els PNG retornats amb Pillow.

Configuració opcional en `.env`:

```env
IMAGE_A1111_URL=http://127.0.0.1:7860
IMAGE_A1111_MODEL=
IMAGE_GENERATION_DIR=./data/generated-images
```

Cal iniciar AUTOMATIC1111 o Forge amb la seua API activada. Si Pomodoro Studio corre en Docker, `127.0.0.1` apunta al contenidor; cal configurar una URL del host accessible des del contenidor, habitualment `http://host.docker.internal:7860` quan la plataforma ho admet.

El connector envia prompt positiu/negatiu, amplària, altura, passos i CFG; pot seleccionar un checkpoint opcional i desa la imatge retornada en la carpeta de generació. `generate_image()` és el punt d'entrada únic perquè la resta de l'aplicació no depenga de l'API concreta.

### Proves

Hi ha proves per a prompts, presets, composicions, detecció de referències, importació i procedència, arquitectura de proveïdors i resposta simulada d'A1111/Forge. La CI no necessita un servidor Stable Diffusion real.

## Flux web complet

Des de qualsevol projecte, inclús sense fons previs, el constructor manté el mode manual i la còpia de prompts. El selector de proveïdors mostra els connectors configurats; A1111/Forge continua sent opcional.

1. Selecciona un proveïdor i prem **Generar imatge**. La petició usa el constructor validat al servidor.
2. Revisa la previsualització temporal. Encara no apareix al catàleg de fons.
3. Indica nom, llicència i notes i prem **Acceptar com a fons**.
4. El resultat es copia a `assets/backgrounds` amb JSON de procedència (prompts, proveïdor, model, notes del proveïdor, paràmetres, llicència i data). La pàgina selecciona el nou fons.

API JSON per projecte: `GET /api/projects/{id}/ambience/providers`, `POST .../generate`, `GET .../{token}/preview` i `POST .../{token}/accept`. La generació rep `provider`, `spec` i opcionalment `width`, `height`, `steps`, `cfg_scale`; l'acceptació rep `name`, `license`, `source_notes`. No s'accepten rutes de fitxers ni URLs del proveïdor enviades pel navegador.

Els identificadors aleatoris de previsualització estan vinculats al projecte. Es rebutgen travessies de rutes, enllaços simbòlics i peticions web d'origen extern. Les reserves exclusives de fitxers impedixen sobreescriure tant imatges com metadades; un conflicte conserva la previsualització per a reintentar amb un altre nom. La imatge temporal desapareix després d'acceptar-la. Descartar elimina la imatge temporal i el seu registre amb `DELETE .../{token}`. Els temporals abandonats en tancar la pàgina es conserven en `IMAGE_GENERATION_DIR` i poden netejar-se quan no hi haja generacions pendents.

Els errors de generació es mostren sense revelar respostes internes del servidor. Es comprova que A1111 retorna un PNG decodificable, amb límits de mida. Pillow és la dependència de validació d'imatges. Les proves d'integració simulen el proveïdor; la verificació amb una GPU i un model real queda com a comprovació operativa del desplegament.

La PR #8 es va fusionar a `main` amb autorització explícita. La suite d’aquella entrega va superar 99 proves i la CI #260 va acabar en verd. Estes xifres són històriques, no el resultat dels canvis posteriors de documentació.

## Principis

- Pomodoro Studio funciona completament sense IA.
- Cap credencial o secret entra al repositori.
- La importació manual continua sent una opció de primera classe.
- La generació local és explícita i opcional.
- La revisió humana precedix la incorporació definitiva d'un recurs.
- No es pretén reproduir franquícies, personatges, logotips ni estils identificables d'una obra concreta.

## Posada en marxa local documentada

La [guia Linux Mint](INSTAL_LINUX_MINT.md) recull el muntatge de Forge en Python 3.10 separat de Pomodoro, les correccions de CLIP/pkg_resources i NumPy/scikit-image i la connexió via `.env`. En l’equip reportat (Mint 22.3, RTX 3060 de 12 GB i 32 GB de RAM), l’usuari ha confirmat l’arrancada de Forge després de corregir les dependències. Això no equival encara a certificar una generació completa des de Pomodoro.

També es documenten els [accessos directes](ACCESSOS_DIRECTES.md) i la [biblioteca d’àudio i llicències](AUDIO_I_LLICENCIES.md). Vídeo, efectes i música generats localment continuen sent fluxos externs; no s’han afegit connectors nous per a ells.
