# v0.8 — Ambientacions originals

La v0.8 prioritza la creació d'ambientacions originals assistida opcionalment per IA, avançant este bloc que inicialment estava previst per a la v0.9.

## Objectiu

Fer que Pomodoro Studio ajude a concebre i preparar una identitat visual original per a cada vídeo sense convertir cap proveïdor d'IA en una dependència obligatòria del nucli.

## Blocs implementats

### 1. Constructor de prompts

`app/services/ambience_prompt.py` incorpora un constructor independent de proveïdor amb camps per a tema, època, lloc, hora, clima, il·luminació, atmosfera, estil visual, detalls i relació d'aspecte.

Genera:

- prompt positiu orientat a fons de vídeo de concentració;
- prompt negatiu per evitar text, logos, marques d'aigua, UI i defectes visuals;
- composició 16:9 per defecte;
- validació abans de lliurar el prompt.

### 2. Presets originals

S'inclouen bases genèriques per a biblioteca, cabana, observatori, bosc, taverna i estació espacial. Els presets són simples dades i no depenen de cap API ni model concret.

### 3. Control d'originalitat

El constructor detecta referències directes a una primera llista de franquícies i universos coneguts i rebutja el prompt abans de generar-lo. L'objectiu no és determinar jurídicament si una idea és acceptable, sinó impedir que el flux normal de Pomodoro Studio es base en copiar noms, personatges, emblemes o mons identificables.

La descripció final reforça món original, arquitectura genèrica i absència de personatges o marques recognoscibles.

### 4. Importació i procedència

`app/services/ambience_assets.py` permet importar JPG, JPEG, PNG i WebP a la biblioteca de fons sense sobreescriure recursos existents.

Cada importació crea un JSON lateral amb:

- prompt i prompt negatiu;
- proveïdor;
- model;
- llicència o situació de drets indicada per l'usuari;
- notes de procedència;
- data d'importació;
- nom del recurs final.

Això permet conservar la traçabilitat encara que la imatge s'haja creat fora de Pomodoro Studio.

### 5. Proves

Hi ha proves específiques per al constructor, presets, relacions d'aspecte, detecció de referències, normalització de noms, formats d'importació, metadades de procedència i protecció contra sobreescriptura.

## Següents blocs

1. Integrar el constructor de prompts en la interfície web.
2. Afegir variants específiques per a miniatura i composició amb zona lliure per al text.
3. Definir una interfície de proveïdors opcionals perquè un generador local o extern puga connectar-se sense contaminar el nucli.
4. Permetre guardar variants pròpies d'ambientació.
5. Completar documentació d'ús manual, local i amb proveïdor extern.

## Principis

- Pomodoro Studio funciona completament sense IA.
- Cap credencial o secret entra al repositori.
- La importació manual continua sent una opció de primera classe.
- La revisió humana precedix la incorporació definitiva d'un recurs.
- No es pretén reproduir franquícies, personatges, logotips ni estils identificables d'una obra concreta.
