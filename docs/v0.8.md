# v0.8 — Ambientacions originals

La v0.8 prioritza la creació d'ambientacions originals assistida opcionalment per IA, avançant este bloc que inicialment estava previst per a la v0.9.

## Objectiu

Fer que Pomodoro Studio ajude a concebre i preparar una identitat visual original per a cada vídeo sense convertir cap proveïdor d'IA en una dependència obligatòria del nucli.

## Blocs implementats

### Constructor de prompts i composicions

`app/services/ambience_prompt.py` genera prompts positius i negatius amb tema, època, lloc, hora, clima, il·luminació, atmosfera, estil i detalls. Hi ha composicions per a fons 16:9 i miniatures amb espai de text a esquerra, dreta o focus central.

La interfície web carrega el constructor dins de la fitxa del projecte i permet copiar els prompts sense necessitar cap servei d'IA.

### Presets i variants pròpies

S'inclouen bases genèriques per a biblioteca, cabana, observatori, bosc, taverna i estació espacial. La UI permet guardar, recuperar i eliminar variants pròpies. Estes variants es conserven en `localStorage` del navegador, de manera que no exigixen migracions de base de dades en la v0.8.

### Control d'originalitat

El constructor rebutja referències directes a una primera llista de franquícies i universos coneguts. El prompt final reforça món original, arquitectura genèrica i absència de personatges, logotips o marques recognoscibles. És una protecció de producte, no una determinació jurídica automàtica.

### Importació i procedència

`app/services/ambience_assets.py` importa JPG, JPEG, PNG i WebP sense sobreescriure recursos existents i crea un JSON lateral amb prompt, prompt negatiu, proveïdor, model, llicència, notes, data i nom final.

### Proveïdors opcionals

`app/services/image_providers.py` manté una interfície comuna. El mode `manual` continua sempre disponible i no genera res automàticament.

La v0.8 incorpora un connector real per a **AUTOMATIC1111 / Stable Diffusion WebUI Forge** mitjançant l'API compatible `/sdapi/v1/txt2img`. No hi ha dependències noves: usa `httpx`, que ja forma part del projecte.

Configuració opcional en `.env`:

```env
IMAGE_A1111_URL=http://127.0.0.1:7860
IMAGE_A1111_MODEL=
IMAGE_GENERATION_DIR=./data/generated-images
```

Cal iniciar AUTOMATIC1111 o Forge amb la seua API activada. Si Pomodoro Studio corre en Docker, `127.0.0.1` apunta al contenidor; cal configurar una URL del host accessible des del contenidor, habitualment `http://host.docker.internal:7860` quan la plataforma ho admet.

El connector envia prompt positiu/negatiu, amplària, altura, passos i CFG; pot seleccionar un checkpoint opcional i desa la imatge retornada en la carpeta de generació. `generate_image()` és el punt d'entrada únic perquè la resta de l'aplicació no depenga de l'API concreta.

### Proves

Hi ha proves per a prompts, presets, composicions, detecció de referències, importació i procedència, arquitectura de proveïdors i resposta simulada d'A1111/Forge. La CI no necessita un servidor Stable Diffusion real.

## Pendent abans de tancar v0.8

1. Exposar `generate_image()` com a acció segura de la interfície FastAPI i mostrar la imatge generada abans d'acceptar-la.
2. Incorporar l'acceptació del resultat a `assets/backgrounds/` reutilitzant el registre de procedència.
3. Afegir errors visibles de connexió/model/memòria GPU sense filtrar detalls interns innecessaris.
4. Actualitzar README i guia d'ús amb el flux complet.
5. Revisió final, proves i CI verda.

## Principis

- Pomodoro Studio funciona completament sense IA.
- Cap credencial o secret entra al repositori.
- La importació manual continua sent una opció de primera classe.
- La generació local és explícita i opcional.
- La revisió humana precedix la incorporació definitiva d'un recurs.
- No es pretén reproduir franquícies, personatges, logotips ni estils identificables d'una obra concreta.
