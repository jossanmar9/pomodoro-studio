# Pomodoro Studio v0.4

## Objectiu

Fer que el motor de renderitzat siga més ràpid, configurable i adequat per a produir vídeos llargs de manera habitual, aprofitant acceleració per GPU quan estiga disponible sense perdre compatibilitat amb CPU.

## Abast previst

- Afegir perfils de qualitat de renderitzat per a 1080p i 1440p.
- Permetre seleccionar el motor de vídeo: automàtic, CPU (`libx264`) o NVIDIA NVENC (`h264_nvenc`).
- Detectar si FFmpeg disposa de NVENC i fer fallback segur a CPU en mode automàtic.
- Centralitzar la construcció de les ordres FFmpeg perquè siguen fàcils de provar i mantindre.
- Millorar la mescla d'àudio amb guanys validats i transicions suaus d'entrada/eixida.
- Persistir amb el projecte la configuració utilitzada per al renderitzat quan siga necessari per a repetir-lo.
- Mostrar en la interfície el perfil i motor seleccionats abans de començar el renderitzat.
- Afegir tests per a ordres CPU/NVENC, detecció de capacitats, fallback i configuracions incorrectes.
- Mantindre compatibilitat amb els projectes creats en versions anteriors.

## Primera fase

1. Separar la configuració de codificació de la lògica general del renderer.
2. Implementar detecció de `h264_nvenc`.
3. Crear els perfils de qualitat inicials.
4. Cobrir la generació d'ordres FFmpeg amb tests abans de connectar-ho a la interfície.

## Fora d'abast inicial

- Publicació automàtica a YouTube.
- Generació d'imatges o música amb IA.
- Dependència obligatòria d'una GPU NVIDIA.
- Codificació AV1 com a requisit de la v0.4.

La v0.4 no es considerarà acabada fins que el camí CPU continue funcionant, NVENC siga opcional i la CI final estiga en verd.
