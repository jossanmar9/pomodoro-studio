# Pomodoro Studio v0.4

## Objectiu

Fer que el motor de renderitzat siga més ràpid, configurable i adequat per a produir vídeos llargs de manera habitual, aprofitant acceleració per GPU quan estiga disponible sense perdre compatibilitat amb CPU.

## Implementat

- Tres perfils de qualitat: **Ràpid**, **Equilibrat** i **Qualitat alta**.
- Motor seleccionable: **Automàtic**, **CPU (`libx264`)** o **NVIDIA NVENC (`h264_nvenc`)**.
- Detecció de `h264_nvenc` a través de FFmpeg.
- Mode automàtic: NVENC quan està disponible i CPU quan no ho està.
- Fallback addicional a CPU si un renderitzat NVENC arriba a iniciar-se però FFmpeg falla.
- Configuració d'encoding separada del renderer general i fàcil de provar.
- Compatibilitat amb 1080p i 1440p.
- Persistència per projecte del motor demanat, perfil de qualitat i últim motor real utilitzat mitjançant una taula nova, sense trencar bases de dades de versions anteriors.
- Duplicació de projectes conservant el motor i perfil preferits.
- Controls de motor i qualitat en la pantalla de preparació del vídeo.
- Indicació en la interfície de si NVENC està disponible.
- API d'estat ampliada amb motor real i indicador de fallback.
- Mescla d'àudio amb volums independents, limitador final i fades suaus de dos segons a l'entrada i l'eixida.
- Tests específics de CPU, NVENC, selecció automàtica, fallback per indisponibilitat, perfils i construcció de l'ordre FFmpeg.

## Perfils

### Ràpid

- CPU: `libx264`, preset `fast`, CRF 23.
- NVENC: `h264_nvenc`, preset `p4`, CQ 24.

### Equilibrat

- CPU: `libx264`, preset `medium`, CRF 20.
- NVENC: `h264_nvenc`, preset `p5`, CQ 21.

### Qualitat alta

- CPU: `libx264`, preset `slow`, CRF 18.
- NVENC: `h264_nvenc`, preset `p6`, CQ 18.

## Compatibilitat

NVENC és completament opcional. Una instal·lació sense GPU NVIDIA o sense suport NVENC continua funcionant amb CPU. La configuració nova es guarda en una taula independent (`render_configs`), de manera que `create_all` pot afegir-la a una base SQLite existent sense necessitat d'afegir columnes a `projects`.
