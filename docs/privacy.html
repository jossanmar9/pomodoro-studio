POMODORO STUDIO

Privacy Policy

Last updated: 29 October 2026

Pomodoro Studio ("the app") is a personal, self-hosted tool operated by José Vicente Sanjuan to create Pomodoro focus videos and publish them to his own YouTube channel, The Amber Window. This policy explains how the app handles Google user data.

Who uses the app

The app runs only on the owner's own computer. It is not offered as a service to the public and is used only by the channel owner.

What data the app accesses

The app requests a single Google OAuth permission: https://www.googleapis.com/auth/youtube.upload. It uses this permission only to upload videos and their thumbnails, with titles, descriptions and tags written by the app, to the authorised YouTube channel. It does not read the user's videos, comments, subscribers, analytics, contacts, email or any other Google data.

How data is stored

The OAuth token issued by Google is stored only as a local file on the owner's computer, with restricted file permissions. It is never sent to any server other than Google's own APIs, and it is not included in the source code repository.

Sharing

The app does not sell, share or transfer Google user data to anyone. It does not use Google user data for advertising, and it does not use it to train AI or machine-learning models.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube API Services Terms of Service. By using the app, the user also agrees to the YouTube Terms of Service; Google's privacy practices are described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google account's security settings at myaccount.google.com/permissions. Deleting the local token file also removes the app's access on that computer.
