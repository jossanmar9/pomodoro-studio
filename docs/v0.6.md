# v0.6 — Publicació opcional a YouTube

La v0.6 integra una pujada manual a YouTube mantenint Pomodoro Studio plenament usable sense compte de Google.

## Implementat

- OAuth 2.0 d'aplicació d'escriptori amb l'abast mínim `youtube.upload`.
- Token local reutilitzable i refresc automàtic.
- Pujada resumible del vídeo amb YouTube Data API v3 `videos.insert`.
- Títol, descripció, capítols, etiquetes, categoria, idioma i privacitat.
- Miniatura personalitzada amb `thumbnails.set` quan existeix.
- Privacitat `private` per defecte, amb opcions `unlisted` i `public` explícites.
- Persistència de l'estat, ID de vídeo i últim error per projecte.
- Interfície de publicació dins de la fitxa del projecte.
- Dependències de Google separades en `requirements-youtube.txt`.
- Credencials i tokens exclosos de Git.
- Tests de validació sense usar credencials reals ni fer pujades.

## Configuració

1. Crea un projecte a Google Cloud i activa YouTube Data API v3.
2. Crea un client OAuth de tipus Desktop app.
3. Descarrega el JSON com `data/youtube-client-secret.json`.
4. Instal·la `pip install -r requirements-youtube.txt`.
5. Genera un vídeo i prem `Publicar a YouTube`.
6. La primera vegada s'obrirà el navegador per autoritzar el canal. El token queda en `data/youtube-token.json`.

No es publica res automàticament: la pujada només s'inicia amb una acció explícita de l'usuari.
